# فارسی‌یار | ابزار هوشمند تدریس فارسی چهارم

این نسخه برای کلاس واقعی طراحی شده است و علاوه بر حالت آفلاین، زیرساخت کلاس چنددستگاهی Realtime را دارد.

## قابلیت‌های آنلاین
- ساخت کلاس با کد FAR-xxxx
- ورود چند دانش‌آموز با گوشی‌های جداگانه
- ارسال زنده مأموریت معلم
- دریافت پاسخ‌ها روی گوشی معلم
- امتیازدهی و تابلو امتیاز مشترک
- پیام زنده معلم
- همگام‌سازی درس انتخاب‌شده
- بازی‌ها و ابزارهای تدریس موجود در نسخه قبلی

## راه‌اندازی آنلاین
1. فایل `supabase-schema.sql` را در SQL Editor پروژه Supabase اجرا کن.
2. در Supabase از بخش Project Settings > API، مقدار **Project URL** و **anon/public key** را بردار.
3. فایل `supabase-config.js` را باز کن.
4. مقدار `FARSYAR_SUPABASE_URL` را با Project URL و مقدار `FARSYAR_SUPABASE_ANON_KEY` را با anon/public key پر کن.
5. `index.html` را روی هاست HTTPS مثل GitHub Pages منتشر کن.

> فقط anon/public key مجاز است. service_role key را هرگز داخل سایت قرار نده.

اگر کلید وارد نشود، برنامه همچنان در حالت تک‌دستگاهی/آفلاین کار می‌کند.
