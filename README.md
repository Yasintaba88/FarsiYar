# فارسی‌یار | کلاس زندهٔ فارسی چهارم دبستان

نسخهٔ مستقل و آمادهٔ GitHub Pages برای اجرای یک کلاس چنددستگاهی با **HTML + CSS + JavaScript خالص** و **Supabase Auth / Postgres / Realtime**.

## فایل‌ها

- `index.html` — رابط کاربری اصلی، راست‌چین و موبایل‌محور
- `style.css` — طراحی فیروزه‌ای/سرمه‌ای/طلایی با نقش کاشی و Dark Mode خودکار
- `app.js` — منطق Auth، کلاس زنده، مأموریت‌ها، پاسخ‌ها، امتیاز، تخته و گزارش
- `data.js` — ۱۷ درس، مسیر پنج‌مرحله‌ای و لینک‌های دقیق کتاب
- `supabase-config.js` — URL و Publishable key پروژه
- `supabase-schema.sql` — جداول، RLS، توابع امن و Realtime
- `supabase-fix.sql` — اصلاح ساخت کلاس از طریق RPC و اصلاح محاسبه امتیاز
- `book/chaharom-farsi-1404.pdf` — کتاب فارسی چهارم پیوست پروژه

## ۱) ساخت Supabase

1. وارد پروژهٔ Supabase شوید.
2. بخش **SQL Editor** را باز کنید.
3. اگر دیتابیس تازه است، کل محتوای `supabase-schema.sql` را اجرا کنید.
4. سپس فایل `supabase-fix.sql` را اجرا کنید؛ نسخهٔ فعلی `app.js` برای ساخت کلاس به تابع `create_farsiyar_class()` نیاز دارد. اگر جدول‌ها از قبل وجود دارند، ابتدا نسخهٔ پشتیبان بگیرید و فقط SQL اصلاحی را پس از بررسی اجرا کنید.
5. اگر جدول یا تابعی قبلاً وجود داشته، خطاهای SQL را کامل بررسی کنید و از حذف جدول‌ها خودداری کنید.
6. در **Authentication → Providers → Email** ورود ایمیلی را فعال نگه دارید.
7. ثبت‌نام عمومی را خاموش کنید و حساب معلم را از پنل Authentication بسازید.
8. اگر تأیید ایمیل روشن است، ایمیل معلم باید تأیید شده باشد.

### امنیت Supabase

- داخل مرورگر فقط **Publishable key** قرار دارد.
- `service_role` و secret key هرگز در فایل‌های این پروژه قرار نگرفته‌اند.
- جدول کلاس فقط توسط مالک Auth قابل نوشتن، ویرایش و حذف است.
- پاسخ‌ها فقط برای نام موجود در roster قابل درج هستند و مشاهدهٔ پاسخ‌ها برای مالک کلاس است.
- امتیازدهی مستقیم از جدول مسدود است و فقط از تابع `award_farsiyar_points` با `security definer`، بررسی مالکیت، بررسی roster و محدودیت `-3..+3` انجام می‌شود.
- دانش‌آموز برای خواندن کلاس و تابلو امتیاز از RPCهای محدودشده استفاده می‌کند؛ SELECT عمومی روی جدول کلاس و امتیاز باز نشده است.
- RLS روی هر سه جدول فعال است.

> کد کلاس مانند یک «کلید ورود کلاسی» عمل می‌کند. بنابراین کد کلاس را فقط برای دانش‌آموزان همان کلاس ارسال کنید.

## ۲) تنظیم `supabase-config.js`

مقادیر زیر را با اطلاعات پروژهٔ خودتان جایگزین کنید:

```js
window.FARSYAR_SUPABASE_URL = 'https://YOUR_PROJECT.supabase.co';
window.FARSYAR_SUPABASE_PUBLISHABLE_KEY = 'sb_publishable_...';
```

در این فایل **هرگز** `service_role` یا secret key قرار ندهید.

## ۳) GitHub Pages

ساختار repository را همین‌طور نگه دارید:

```text
FarsiYar/
├── index.html
├── style.css
├── app.js
├── data.js
├── supabase-config.js
├── supabase-schema.sql
├── README.md
└── book/
    └── chaharom-farsi-1404.pdf
```

سپس:

1. همهٔ فایل‌ها را در شاخهٔ `main` آپلود کنید.
2. در GitHub وارد **Settings → Pages** شوید.
3. Source را روی **Deploy from a branch** بگذارید.
4. Branch را `main` و پوشه را `/(root)` انتخاب کنید.
5. چند لحظه صبر کنید تا GitHub Pages منتشر شود.

## ۴) ورود معلم

- دکمهٔ «اتاق معلم» را بزنید.
- ایمیل و رمز همان کاربری را که در Supabase Authentication ساخته‌اید وارد کنید.
- اگر خطا رخ دهد، پیام فارسی زیر دکمه مشخص می‌کند که مشکل از رمز، کاربر، تأیید ایمیل، جدول‌ها، کلید یا اینترنت است.

## ۵) ورود دانش‌آموز

معلم در «کلاس زنده» کد کلاس و لینک ورود را می‌بیند. دانش‌آموز:

1. لینک را باز می‌کند.
2. کد `FAR-1234` را وارد می‌کند یا از لینک دارای `?class=FAR-1234` وارد می‌شود.
3. «دریافت فهرست کلاس» را می‌زند.
4. نام ثبت‌شدهٔ خودش را انتخاب می‌کند.
5. وارد پنل دانش‌آموز می‌شود.

دانش‌آموز هیچ صفحهٔ Auth معلم یا پنل مدیریت کلاس را نمی‌بیند.

## ۶) قابلیت‌های کلاسی

### معلم

- انتخاب هر ۱۷ درس کتاب
- مسیر پنج‌مرحله‌ای مخصوص هر درس
- لینک مستقیم درس، «بخوان و حفظ کن»، «بخوان و بیندیش»، حکایت، مَثَل، نیایش و واژه‌نامه با `#page=N`
- ویدیوی آموزشی درس
- ساخت چهار نوع مأموریت زنده:
  - پاسخ نوشتاری
  - چهارگزینه‌ای با تصحیح خودکار
  - املای صوتی با `speechSynthesis` فارسی و مقایسهٔ پاسخ
  - جمله‌ساز با چیدن واژه‌ها و مقایسهٔ پاسخ
- دریافت لحظه‌ای پاسخ‌ها
- امتیازدهی دستی +۱، +۲ و +۳
- پیام زنده
- تابلو امتیاز
- چاپ گزارش
- خروجی JSON
- گردونهٔ انتخاب تصادفی دانش‌آموز
- زمان‌سنج ۶۰ ثانیه‌ای
- تختهٔ هوشمند با قلم، پاک‌کن، برگشت و پاک‌کردن
- فهرست ۲۹ دانش‌آموز
- ساخت کلاس جدید و حذف کلاس فعلی

### دانش‌آموز

- درس امروز
- پیام معلم
- مأموریت فعال
- ارسال پاسخ
- تصحیح فوری فعالیت‌های بسته
- امتیاز شخصی
- تابلو افتخار
- باز کردن مستقیم درس در PDF
- مشاهدهٔ تختهٔ معلم به‌صورت زنده

## ۷) لینک صفحات PDF

شماره‌های `#page=N` از مقصد لینک‌های داخلی فهرست خود PDF پیوست استخراج شده‌اند، نه از حدس شماره صفحه. در PDF این فایل، صفحات فهرست به مقصدهای داخلی مانند ۱۰، ۱۸، ۳۰، ۳۶، ۴۲، ۵۴، ۶۲، ۷۴، ۷۷، ۸۰، ۸۸، ۹۴، ۱۰۴، ۱۰۸، ۱۱۲، ۱۲۴ و ۱۳۰ وصل هستند؛ همچنین نیایش به ۱۴۰ و واژه‌نامه به ۱۴۱ متصل است.

## ۸) تست انجام‌شده

این پروژه با ابزارهای موجود در این محیط از نظر فایل و کد بررسی شده است:

- `node --check app.js` و `node --check data.js` با موفقیت اجرا شدند.
- فایل PDF کتاب در بستهٔ نهایی قرار داده شد و تعداد ۱۵۲ صفحهٔ فایل بررسی شد.
- ساختار فایل‌ها و PDF همراه پروژه بررسی شد.
- `unzip -t` روی بستهٔ نهایی اجرا می‌شود و باید بدون خطا باشد.
- مقصدهای داخلی لینک‌های فهرست PDF با `pypdf` بررسی شدند و شماره صفحه‌های مقصد با دادهٔ `data.js` تطبیق داده شدند.

**تست واقعی مرورگر headless و تست زندهٔ شبکه علیه Supabase در این محیط انجام نشده است**؛ ابزار Playwright/Chromium headless در دسترس نبود و به همین دلیل ادعا نمی‌شود که ورود Auth، Realtime بین دو دستگاه و policyهای واقعی Supabase در مرورگر آنلاین تست شده‌اند. این بخش باید پس از اجرای SQL و انتشار GitHub Pages در محیط واقعی شما تست شود.

## ۹) محدودیت‌ها

- ورود دانش‌آموز با انتخاب نام از فهرست به‌تنهایی هویت را اثبات نمی‌کند؛ برای استقرار حساس، PIN/توکن دانش‌آموز باید در سمت سرور اعتبارسنجی شود.
- امتیاز فعالیت‌های بسته در حال حاضر پاسخ صحیح را ثبت می‌کند، اما برای فعالیت نوشتاری آزاد نمرهٔ زبانی/معنایی هوشمند ندارد.
- املای صوتی به `speechSynthesis` مرورگر وابسته است و کیفیت صدای فارسی بسته به دستگاه و مرورگر متفاوت است.
- جمله‌ساز بر اساس `answerKey` تعریف‌شده توسط معلم تصحیح می‌شود و مدل زبانی برای پذیرش همهٔ جمله‌های هم‌معنی ندارد.
- گردونه و زمان‌سنج برای اتاق معلم هستند و وضعیت آن‌ها به‌عنوان ابزار کمکی ذخیره نمی‌شود.
- تختهٔ هوشمند به‌صورت مسیرهای برداری ذخیره می‌شود؛ تصویر/فایل قلمی جداگانه تولید نمی‌کند.
- برای دانش‌آموز، انتخاب نام به‌تنهایی احراز هویت هویتی محسوب نمی‌شود؛ این طراحی عمداً برای کلاس مدرسه و ورود سریع با کد کلاس است. برای محیط حساس‌تر باید احراز هویت دانش‌آموز اضافه شود.
- کد کلاس باید محرمانهٔ کلاسی باقی بماند.
- ویدیوهای خارجی به YouTube وابسته‌اند؛ برای بعضی درس‌ها لینک جست‌وجوی دقیق YouTube قرار داده شده چون لینک ویدیوی مستقیم قابل اتکایی برای آن درس در منبع بررسی‌شده در دسترس نبود.
- این پروژه بدون build و framework نوشته شده است و برای تغییر کد کافی است فایل‌های معمولی repository را ویرایش کنید.
