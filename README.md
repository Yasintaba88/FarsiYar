# فارسی‌یار — بستهٔ بازسازی‌شده

این بسته شامل فایل‌های سایت، منطق کامل `app.js`، دادهٔ ۱۷ درس، کتاب PDF و فایل‌های SQL است.

## فایل‌ها
- `index.html` — رابط کاربری فارسی و راست‌چین
- `style.css` — ظاهر واکنش‌گرا
- `app.js` — منطق ورود معلم، کلاس زنده، مأموریت‌ها، پاسخ‌ها، امتیاز، تخته و گزارش
- `data.js` — درس‌ها و مسیرهای تدریس
- `supabase-config.js` — آدرس و Publishable key پروژه
- `supabase-schema.sql` — ساخت دیتابیس تازه
- `supabase-fix.sql` — بازسازی توابع ساخت کلاس و امتیازدهی
- `supabase-migrate-existing.sql` — مهاجرت کم‌خطر برای جدول‌های قدیمی پروژه
- `book/chaharom-farsi-1404.pdf` — کتاب پیوست

## برای مخزن فعلی GitHub Pages
1. از مخزن فعلی یک نسخه پشتیبان/کپی بگیر.
2. محتویات پوشهٔ `FarsiYar-fixed` را در ریشهٔ شاخهٔ `main` قرار بده؛ ساختار پوشهٔ `book` باید حفظ شود.
3. `supabase-config.js` از قبل آدرس و Publishable key اعلام‌شده برای پروژه را دارد. کلیدهای `service_role` یا `secret` را هرگز در مرورگر قرار نده.
4. چون دیتابیس فعلی قدیمی است، **فعلاً `supabase-schema.sql` را دوباره اجرا نکن**. از SQL Editor یک نسخه پشتیبان بگیر و فقط `supabase-migrate-existing.sql` را اجرا کن. این فایل ردیف‌ها را حذف نمی‌کند؛ اگر داده‌های تکراری در امتیازها باشد، با پیام روشن متوقف می‌شود و چیزی را پاک نمی‌کند.
5. پس از انتشار GitHub Pages، صفحه را در یک برگه ناشناس باز کن تا فایل‌های قبلی از حافظهٔ مرورگر استفاده نشوند.

## نکتهٔ آزمون
فایل‌های JavaScript با `node --check` بررسی شده‌اند. این محیط امکان اتصال واقعی به Supabase پروژهٔ شما یا اجرای تست مرورگر آنلاین را ندارد؛ بنابراین ورود Auth، RLS و Realtime باید پس از بارگذاری در پروژهٔ واقعی بررسی شوند.
