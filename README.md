# فارسی‌یار V6 — سامانه کلاس زنده فارسی چهارم دبستان

نسخه نهاییِ بازطراحی‌شده برای GitHub Pages + Supabase. رابط کاملاً RTL، موبایل‌محور و بدون framework/build است.

## امکانات
- ورود امن معلم با Supabase Auth؛ هیچ رمز معلمی داخل کد نیست.
- ساخت کلاس با کد `FAR-1234` و حداکثر ۲۹ دانش‌آموز.
- ورود دانش‌آموز با انتخاب نام + PIN اختصاصی؛ نام به‌تنهایی مجوز ارسال پاسخ نیست.
- ۱۷ درس کتاب فارسی چهارم + پنج مرحله تدریس.
- مقصدهای PDF بر اساس لینک‌های داخلی فهرست مطالب خود فایل استخراج شده‌اند؛ برای نمونه درس اول به PDF page 6 و درس هفدهم به PDF page 130 می‌رود.
- مأموریت زنده: نوشتاری، چهارگزینه‌ای با نمره خودکار، دیکته با SpeechSynthesis و نمره‌دهی نرمال‌سازی‌شده، جمله‌سازی.
- پاسخ‌های زنده، امتیازدهی معلم از ۱ تا ۳، جدول افتخار و گزارش.
- تخته برداری با قلم، پاک‌کن، ضخامت، رنگ، undo/redo/clear و همگام‌سازی Realtime.
- قرعه‌کشی، تایمر، پیام زنده، چاپ گزارش و خروجی JSON.
- تم روشن/تیره و UI مناسب موبایل.

## راه‌اندازی Supabase
1. وارد پروژه Supabase شوید.
2. در SQL Editor کل فایل `supabase-schema.sql` را یک‌جا اجرا کنید.
3. در Authentication → Users یک کاربر معلم بسازید و ایمیل را تأیید کنید.
4. در Authentication → Providers / Email، ثبت‌نام عمومی ایمیلی را خاموش نگه دارید؛ حساب معلم را از پنل خود Supabase بسازید. اگر پروژه شما تنظیم جداگانه‌ای برای anonymous sign-in دارد، برای این نسخه لازم نیست فعال باشد.
5. فایل `supabase-config.js` را با URL پروژه و publishable key خودتان تنظیم کنید. هرگز service_role را وارد سایت نکنید.

### اگر جدول‌ها قبلاً از نسخه‌های قبلی وجود دارند
این schema جدول‌ها و policyهای V6 را به‌روزرسانی می‌کند، اما اگر ساختار قبلی ستون‌های ناسازگار داشته باشد ممکن است لازم باشد جدول‌های `farsiyar_*` قدیمی را قبل از اجرای schema حذف کنید. اگر داده مهمی دارید، ابتدا backup بگیرید.

## GitHub Pages

## تست انجام‌شده در این بسته
- ساختار ZIP و وجود همه فایل‌های اصلی بررسی شده است.
- JavaScript با `node --check` بررسی می‌شود.
- مسیرهای PDF از annotationهای داخلی فهرست مطالب فایل ۱۴۰۴ استخراج شده‌اند، نه با حدس اختلاف شماره صفحه.
- تست واقعی مرورگر، Login و Realtime روی یک پروژه Supabase زنده در این محیط انجام نشده است؛ بنابراین پس از اجرای SQL یک بار ورود معلم، ساخت کلاس و ورود دو دستگاه را دستی تست کنید.

## نکته مهم درباره کتاب
فایل PDF کتاب دارای اعلام حقوق نشر است. اگر repository را عمومی می‌کنید، فقط در صورتی فایل کتاب را عمومی کنید که مجوز لازم برای بازنشر آن را دارید؛ در غیر این صورت PDF را از ZIP عمومی حذف و در پروژه از منبع قانونی/مجاز خودتان استفاده کنید.

## محدودیت‌های طبیعی
- تشخیص گفتار و تبدیل صدای دانش‌آموز به متن به امکانات مرورگر وابسته است؛ نسخه V6 برای دیکته از SpeechSynthesis برای پخش و الگوریتم متنی برای ارزیابی استفاده می‌کند، نه مدل تشخیص صدای سروری.
- ویدئوهای مشخص‌شده به YouTube متصل‌اند؛ بعضی درس‌ها لینک جست‌وجوی موضوعی دارند تا لینک ویدئوی نامطمئن جعل نشود.
- GitHub Pages به‌تنهایی backend نیست؛ Realtime و امنیت توسط Supabase انجام می‌شود.
